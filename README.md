# AIdeev

AIdeev is a Telegram bot and video generation aggregator.

The project allows users to generate videos using different AI video models through APIs.

## Features

- 🎬 AI video generation
- 🤖 Telegram bot
- 🔌 Multiple AI video APIs
- ⚡ Simple command-based interface

## Tech Stack

- Node.js
- Telegram Bot API
- AI video APIs

## Project

AIdeev is an open-source project focused on bringing multiple AI video generation models into one Telegram bot.
